Favourite Student List – React

A modern React application for managing favourite students using React Router and Context API.

✨ Features
👨‍🎓 Dynamic student list
❤️ Add & remove favourites
🚫 Prevent duplicate favourites
🧭 React Router navigation
🌐 Global state with useContext
📱 Responsive modern UI
✨ Glassmorphism & gradient design
🛠️ Tech Stack
React JS
JavaScript
React Router DOM
Context API
CSS
Vite
🚀 Run Locally
npm install
npm run dev
🎯 Concepts Practiced

useState • useContext • createContext • map() • Conditional Rendering • React Router • <Link>
